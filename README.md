# portfolio

Aman Valiyakath's portfolio, built with Next.js, Tailwind CSS and Google Sans Flex.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
npm run lint
```

## Where things live

| Path | What's there |
| --- | --- |
| `src/app/` | Routes: `/`, `/art`, `/dev`, plus the gooey experiments at `/auto`, `/goey` and `/merge` |
| `src/content/` | Project copy and social links. Edit these to update the site's text |
| `src/components/navigation/` | The floating pill and top nav. `pillConfig.tsx` maps each section to what the pill shows |
| `src/hooks/usePillAnimation.ts` | The pill's scroll-driven position and scale |
| `src/lib/github.ts` | Live star counts for `/dev`, cached with `use cache` |

## Adding a section to the pill

Give `<TrackedSection>` a `section` name and add a matching entry to `SECTION_CONFIG`. `left` and `right` are always visible; `extraLeft` and `extraRight` appear when the pill is hovered, focused or tapped. `<DismissButton />` hides the pill until the next section.

## Regenerating the shapes

The morphing shapes and the favicon are generated by [expressive-shapes](https://github.com/amansxcalibur/expressive-shapes):

```bash
pip install expressive-shapes==0.2.0
python scripts/generate-shapes.py
```
